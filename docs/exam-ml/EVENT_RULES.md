# UniVerse Module E: Observation Event Rules & Mathematical Formulations

This document provides formal mathematical formulations and parameter definitions for the deterministic observation rules operating in UniVerse.

---

## 1. Event A: Repeated Head-Orientation Changes (`repeated_head_orientation_change`)

### 1.1 Purpose
Flags measurable, sustained patterns of head orientation changes away from the active examination viewport for human proctor review. This is **NOT** gaze tracking, attention classification, or cheating inference.

### 1.2 Mathematical Formulation & Pose Extraction
Given the 4x4 facial transformation matrix $M \in \mathbb{R}^{4 \times 4}$ generated by the MediaPipe Face Landmarker, the upper 3x3 rotation sub-matrix $R$ is decomposed into Euler angles (Yaw, Pitch, Roll):

$$R = \begin{bmatrix} r_{00} & r_{01} & r_{02} \\ r_{10} & r_{11} & r_{12} \\ r_{20} & r_{21} & r_{22} \end{bmatrix}$$

Using the standard column-major rotation convention:
$$\text{Yaw} = \text{atan2}(-r_{20}, \sqrt{r_{00}^2 + r_{10}^2}) \times \frac{180}{\pi}$$
$$\text{Pitch} = \text{atan2}(r_{21}, r_{22}) \times \frac{180}{\pi}$$
$$\text{Roll} = \text{atan2}(r_{10}, r_{00}) \times \frac{180}{\pi}$$

### 1.3 Neutral Baseline Calibration
During the candidate's initial preflight setup, an average neutral resting posture $(\text{Yaw}_0, \text{Pitch}_0)$ is recorded. Real-time deviations are evaluated as:
$$\Delta \text{Yaw} = \text{Yaw} - \text{Yaw}_0$$
$$\Delta \text{Pitch} = \text{Pitch} - \text{Pitch}_0$$

### 1.4 Temporal Qualification Rule
A qualifying turn is recorded when:
1. **Threshold Exceeded:** $|\Delta \text{Yaw}| \ge 25.0^\circ$ OR $|\Delta \text{Pitch}| \ge 20.0^\circ$.
2. **Minimum Dwell:** The deviation persists continuously for $t_{\text{dwell}} \ge 0.6\text{ seconds}$ (eliminating sub-second involuntary twitches or tracking noise).
3. **Repeated Pattern:** At least $N \ge 3$ distinct qualifying turns occur within a rolling temporal window of $W = 20.0\text{ seconds}$.
4. **Event Cooldown:** Once emitted, an event enters a cooldown period of $t_{\text{cooldown}} = 30.0\text{ seconds}$.

### 1.5 Confidence Score Attribution
Because head-turn events are derived geometrically from deterministic threshold crossing, **no pseudo-confidence score is fabricated**. The `modelScore` is explicitly stored as `null`, accompanied by factual signal metadata (observed angles, qualifying count, and tracking quality).

## 2. Event B: Person Detected in Restricted Region (`person_detected_in_restricted_region`)

### 2.1 Purpose
Identifies when an Object Detector's `person` bounding box persistently intersects a preconfigured, transparently outlined region of interest (ROI) in the camera preview (such as a doorway or prohibited station boundary).

### 2.2 Normalized Coordinate Geometry
All bounding box coordinates and ROI coordinates are normalized to the frame dimensions:
$$\text{Box} = [x_{\text{min}}, y_{\text{min}}, x_{\text{max}}, y_{\text{max}}] \in [0.0, 1.0]^4$$
$$\text{ROI} = [X_{\text{min}}, Y_{\text{min}}, X_{\text{max}}, Y_{\text{max}}] \in [0.0, 1.0]^4$$

### 2.3 Intersection Metric
The intersection rectangle dimensions are:
$$\Delta x = \max(0, \min(x_{\text{max}}, X_{\text{max}}) - \max(x_{\text{min}}, X_{\text{min}}))$$
$$\Delta y = \max(0, \min(y_{\text{max}}, Y_{\text{max}}) - \max(y_{\text{min}}, Y_{\text{min}}))$$
$$\text{Area}_{\text{intersection}} = \Delta x \times \Delta y$$
$$\text{Area}_{\text{box}} = (x_{\text{max}} - x_{\text{min}}) \times (y_{\text{max}} - y_{\text{min}})$$
$$\text{Intersection Ratio} = \frac{\text{Area}_{\text{intersection}}}{\text{Area}_{\text{box}}}$$

### 2.4 Trigger Invariants
1. **Category Filtering:** Filtered strictly to `category === 'person'`. Non-person objects (chairs, phones, backpacks) are discarded.
2. **Intersection Threshold:** $\text{Intersection Ratio} \ge 0.15$ (or detection center point falls inside ROI).
3. **Minimum Dwell:** Incursion persists continuously for $t_{\text{dwell}} \ge 1.0\text{ second}$ (at least 3 consecutive inference samples).
4. **Detection Confidence:** The detector’s raw model score must satisfy $S_{\text{det}} \ge 0.50$.
5. **Cooldown:** $t_{\text{cooldown}} = 30.0\text{ seconds}$.

## 3. Event C: Additional Person Detected (`additional_person_detected`)

### 3.1 Purpose
Flags situations where more than one person is detected in the examination space for prolonged periods, allowing proctors to verify whether another student or unauthorized person is present.

### 3.2 Trigger Invariants
1. Number of detected persons $P_{\text{count}} \ge 2$, where each detection satisfies $S_{\text{det}} \ge 0.50$.
2. Persistence: Multi-person condition persists for $t_{\text{dwell}} \ge 1.2\text{ seconds}$.
3. Cooldown: $30.0\text{ seconds}$.
