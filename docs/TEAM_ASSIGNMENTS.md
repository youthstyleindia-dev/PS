## 2. Coordination Rules & Boundaries Observed

1. **Shared Contract Precedence**: All API contracts, SQLite table definitions, and TypeScript interfaces were defined in `server/src/types` and `server/src/db/schema.sql` before domain logic was implemented.
2. **Single Git Workspace & Non-Destructive Edits**: No destructive Git resets or clean operations were performed. Working tests and user changes were preserved throughout.
3. **Clean-Room Boundary Enforced**: ExMAS Python code and Proctora biometric gaze tracking were strictly prohibited and rejected during implementation.
